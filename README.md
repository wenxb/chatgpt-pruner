# ChatGPT Pruner

一个用于优化 ChatGPT 长对话页面性能的 Chrome 扩展。  
它会自动移除当前页面中过早的对话块，只保留最近的一部分，从而减少页面中的 DOM 数量，缓解长对话导致的卡顿问题。

## 主要功能

- 自动只保留最近的对话块
- 支持自定义保留数量
- 支持手动“立即裁剪”
- 支持分批“恢复一段”历史内容
- 支持开启 / 关闭自动裁剪
- Popup 面板会自动刷新当前状态
- 恢复历史时尽量保持当前滚动位置不乱跳

## 适用场景

当 ChatGPT 对话很长时，页面里会累积大量消息节点，导致：

- 滚动变卡
- 页面响应变慢
- 浏览器占用增加

这个扩展的思路不是修改 ChatGPT 的数据层，而是直接在页面层面减少旧消息节点数量，让当前会话页面更轻一些。

## 工作原理

扩展会在 ChatGPT 页面中监听对话区域的变化：

1. 检测当前页面的对话块
2. 如果数量超过你设置的保留值，只保留最近的部分
3. 更早的对话块会从 DOM 中移除，并暂存在内存中
4. 当你点击“恢复一段”时，会按当前保留数量分批恢复
5. 恢复时会尝试修正滚动位置，减少页面跳动

## 安装方法

### 1. 下载项目

你可以直接克隆仓库：

```
git clone https://github.com/wenxb/chatgpt-pruner
```

或者直接下载 ZIP 后解压。

### 2. 打开扩展管理页

在 Chrome 浏览器地址栏打开：

```
chrome://extensions/
```

### 3. 开启开发者模式

打开右上角的“开发者模式”。

### 4. 加载扩展

点击“加载已解压的扩展程序”，选择项目目录：

```
chatgpt-pruner/
```

加载完成后，刷新网页，就可以在浏览器工具栏看到扩展图标。

## 注意事项

这个扩展是通过操作 ChatGPT 网页中的 DOM 来减轻页面负担，不会上传、同步或分享你的任何数据。
所有处理都在你的本地浏览器中完成，只会对当前打开的 ChatGPT 页面进行 DOM 裁剪与恢复操作。
